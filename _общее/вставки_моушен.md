# Моушен-вставки: справочник для всех сценаристов

Программа «Авто ютуб» умеет рисовать вместо картинки сцены анимированную инфографику: глобус, карту, цифры,
термометр, документ и т. д. (новый движок, версии 235+). Часть вставок ИИ программы ставит сам (немного, в первой
половине ролика). **Сценарист может заказать вставку сам** — тогда она делается обязательно и в любом месте ролика.

## Как заказать
Файл `вставки.txt` рядом с `сцены_генерация.txt` (в той же папке сценария, попадает в архив). Одна строка — одна
вставка, три части через `|`:

```
# Моушен-вставки (строки с # — комментарии)
S012 | термометр | Климат Норильска: ≈ −26,5 °C средняя температура января; −53 °C рекордный январский минимум
S020 | цифра на фото | ≈180 000 жителей
S031 | документ | Парламент Якутии: «Стройку моста предложили остановить», когда — октябрь этого года
```

- **Номер сцены** — сцена, во время которой голос говорит именно это. Вставка идёт в начале сцены вместо её картинки,
  не дольше 12 секунд; если сцена длиннее (в драмах 30–40 с), дальше идёт её картинка. Поэтому ставим вставку на сцену,
  где нужный факт звучит в первых секундах. Картинку для этой сцены всё равно пишем как обычно: она нужна для «цифры на фото»
  и «плашки места» и как запасной вариант.
- **Вид** — из таблицы ниже (по-русски, как в первой колонке).
- **Что показать** — тема (до двоеточия, станет подписью «● ТЕМА» сверху слева) и данные: цифры, единицы, подписи,
  даты, имена — ровно как в тексте озвучки. Ничего не выдумывать: только факты, которые голос говорит в этой сцене
  или рядом.
- Язык подписей — язык ролика (EN-канал → по-английски, драмы ES → по-испански).
- Сколько: 3–8 на ролик 15–20 минут, 5–12 на 40–60 минут. Не две подряд. Не на превью-сцене и не на карточке главы.

## Виды
| Вид | Что рисуется | Когда ставить | Что написать в «что показать» |
|---|---|---|---|
| `цифра` | большое число бежит до значения, подпись разрядкой, черта | одна яркая цифра: рекорд, сумма, расстояние, потери | тема: значение, единица, подпись («Выбросы: 1,8 млн т сернистого газа в год») |
| `цифра на фото` | число прямо поверх картинки сцены | цифра про то, что на картинке: население города, высота, глубина | «≈180 000 жителей» |
| `термометр` | шкала, столбик, 1–3 значения подряд, голубое → красное | температуры: обычная, затем рекорд | тема: значения с подписями через «;» |
| `календарь` | 365 клеток, дни загораются по году | «N дней в году» | тема: N из 365, подпись, легенда («Один год: 50+ дней пурги в году; ■ = день пурги») |
| `проценты` | 10×10 клеток заполняются, крупно «68 %» | «N процентов», «N из 100» | тема: N %, подпись, источник |
| `шкала` | шкала, опорная линия, знакомые точки, герой последним | где герой среди знакомых по одной мерке | тема, 2–5 знакомых со значениями, герой, опорная линия («Северная широта: Москва 55,7°; … Норильск 69° — герой; полярный круг 66,5°») |
| `слой` | силуэт человека на слое льда/снега/грунта/воды, мерка | толщина или глубина слоя | «толщина льда 1,5 м; лёд; под ним вода» |
| `график` | плавная линия по годам, скобка «на сколько изменилось» | величина менялась во времени | тема: год — значение, … (3–8 точек), единица |
| `столбцы` | столбцы, самый большой — акцентом | несколько отдельных значений | тема: название — значение, … |
| `сравнение` | «А против Б», полосы по каждой мере | две стороны по 1–4 мерам | «Италия против Эфиопии: солдат 17 700 / 100 000; пушек 56 / 42» |
| `линия времени` | линия рисуется, даты по очереди, текущая — акцентом | цепочка дат | 3–6 дат с событием, какая из них — «сейчас» |
| `карта` | тёмная рельефная карта, страны залиты, маршрут линией (через полмира — глобус) | страны, маршрут, где что случилось | страны, точки маршрута по порядку |
| `карта рельефа` | рельеф региона, река рисуется линией, ж/д пунктиром, крупная подпись края | важна сама земля: великая река, огромный край, нет дороги | регион, река (англ. название), города, главный первым, «ж/д: да» если про железную дорогу |
| `глобус` | 3D или 2D Земля, облёт, страны, точки, дуги | далёкое место, разные континенты, путь через полмира | места по порядку, страны, подписи к точкам |
| `место` | плашка внизу слева поверх картинки: место и год | действие переходит в новое место/время | «Якутск, река Лена · 2026» |
| `документ` | лист: шапка, заголовок с засечками, подсвеченная цитата, «КОГДА» | решение, письмо, завещание, заголовок газеты, приговор | кто выпустил: «заголовок», точная цитата (если голос цитирует), когда |
| `цитата` | крупные кавычки, слова по одному, автор | дословная цитата с автором | «текст» — автор, год |
| `список` | пункты с номерами по очереди | «три причины», топ | 2–6 пунктов |

## Подсказки по каналам
- **Драмы**: `документ` (завещание, письмо, решение суда), `место` (город и год в начале главы), `цитата`, `линия
  времени` (как всё случилось). Цифры — только суммы и сроки из сюжета.
- **Животные / Доисторические люди**: `глобус`, `карта рельефа`, `шкала` (размеры, широты, глубины), `слой`,
  `цифра`, `сравнение`, `график`.
- **Истории (СССР)**: `цифра`, `сравнение` (тогда и сейчас), `столбцы`, `график`, `документ`, `линия времени`.

Оформление (тёмно-синее или графитовое с оранжевым) и глобус 3D/2D выбирает владелец в настройках канала —
в сценарии их не пишем.
