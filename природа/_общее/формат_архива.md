# Формат сдачи — одинаковый для всех каналов природы

Решения владельца 18.11.2026: пока **только английский** (DE отложен). Каждый канал — своя папка в программе «Авто ютуб» и в репозитории `Omajati/avto-scenarii`:

| Канал | Папка канала (до буквы) | Навык |
|---|---|---|
| Звери (сухопутные звери, рептилии, амфибии) | `Животные - Звери EN` | `nature-animals` |
| Динозавры и доисторический мир | `Животные - Динозавры EN` | `nature-dinos` |
| Морские обитатели | `Животные - Морские EN` | `nature-ocean` |
| Насекомые (плюс пауки, скорпионы, клещи) | `Животные - Насекомые EN` | `nature-insects` |
| Питомцы — не делаем (решение владельца 18.11.2026) | — | — |

Программа берёт язык из конца имени папки (EN), а голос, музыку, монтаж и профиль Octo — из настроек этого канала. В сценарии про канал ничего писать не нужно: важна только папка, куда кладётся архив.

## Архив

Один ролик = один `.zip` с одной папкой `<NN>_<КЛЮЧ>` (номер ролика канала, ключ капсом, например `04_ЛЮТЫЙ_ВОЛК`). Внутри три файла (плюс необязательный `превью_EN.txt`, см. ниже):

```
04_ЛЮТЫЙ_ВОЛК/
  озвучка_EN.txt           чистый текст диктора
  сцены_генерация.txt      REFERENCE R1… (если нужны) и SCENE S001…
  загрузка_YouTube_EN.md   название, превью, описание, теги, категория, Служебное, Проверка
```

Превью — один из двух способов (с версии 214 программы):

1. **Раскладка (рекомендуется).** Четвёртый файл `превью_EN.txt` в формате превью драм (образец — `сценарии/24_БУТЫЛКА/превью_ES.txt`, каталог раскладок — `.claude/skills/drama-scriptwriter/references/10_превью_раскладки.md`): заголовок, строка `РАСКЛАДКА: <буква> — <название>`, разделы `1. ПРОМТ КАРТИНКИ БЕЗ ТЕКСТА`, `2. ТЕКСТ (…)` строками «СЛОВА — цвет[, место]», `3. ПЛАШКА`. Для природы подходят: **C** «Шапка» (зверь во весь кадр, 1–3 огромных слова сверху), **D** «Подвал» (кадр во весь экран, слова снизу), **E** «Кино-кадр» (1–2 очень крупные строки), **F** «Предмет крупно» (одно существо крупно в центре, вопрос сверху слева, ответ снизу справа, жёлтая плашка), **G** «Разделённый экран» (EXTINCT → ALIVE, до/после, маленький и огромный). A, B (чёрная стена с 4–6 строками) и H (документ) — стиль драм, у природы не брать. Цвета: белый, жёлтый, красный, зелёный, оранжевый; у природы слов мало — 1–4 слова, а не мини-история.
2. **Без файла превью.** Раздел «2. Превью» файла загрузки: строка `> промпт` и `- **Текст:** …` (ниже). Программа нарисует картинку на весь кадр и 1–3 слова сверху слева: чёрным с белой обводкой или белым в красной плашке.

Если есть `превью_EN.txt`, программа берёт его; раздел «2. Превью» файла загрузки всё равно заполняется (коротко + 2 запасные идеи).

## озвучка_EN.txt

- Только то, что произносит диктор. Без заголовков глав, пометок [ФОТО], «SCENE», ремарок.
- Ни одной цифры: всё словами («sixty-six million years», «nineteen ninety-five»). Сокращения и единицы — тоже словами («T. rex» → «T. rex» можно, «km» → «kilometers»).
- Абзац = смысловой кусок 2–6 предложений, абзацы разделены пустой строкой. Главы видны только по крючку в первой фразе абзаца.

## сцены_генерация.txt

Плоский текстовый формат программы (как в образце драм `.claude/skills/drama-scriptwriter/example/10_РЕЦЕПТЫ/сцены_генерация.txt` — шапку с блоками MANDATORY RULE… / PROJECT CONTEXT / Recurring characters / Hard rules / SCENES / FINAL CHECK BEFORE EXPORT копировать оттуда и переписывать под ролик):

```
REFERENCE R1. <описание повторяющегося животного/персонажа для сходства>. Style: … no text.

SCENE S001. <что в кадре, крупность, свет>. Style: <стиль канала>, 16:9, no text, no letters, no watermark.

SCENE S002. …
```

- Одна сцена = один абзац, между сценами пустая строка, номера подряд без пропусков.
- **Число сцен — случайное** (решение владельца 18.11.2026): перед сценами выбрать случайно в пределах одной картинки на 6–10 секунд, например для 15 мин `python3 -c "import random;print(random.randint(90,150))"`. Раньше было «одна на 7–8 секунд»: 15 мин ≈ 120 сцен. Проверка считает секунд на сцену и ругается вне 6–10 с.
- Каждая сцена заканчивается стилем и «no text». Стиль у каждого канала свой (см. его навык). Схема сравнения размеров (силуэт человека рядом с животным) — почти в каждом ролике; программа рисует картинки, поэтому схема описывается как картинка без подписей.
- Анатомия: шесть ног у насекомых, восемь у пауков; динозавры по современной науке (перья у тероподов, где доказано); животные без «мультяшности».
- Без крови, без драк крупным планом, без логотипов и без реальных узнаваемых людей.

## загрузка_YouTube_EN.md

Разделы ровно с такими заголовками (программа их читает):

```
# Загрузка YouTube EN: <NN> <рабочее название>

## 1. Название
<название, 40–70 знаков>

## 2. Превью
> <промпт картинки на английском одной строкой: одно животное крупно, масштаб (человек/предмет), фон; верхний левый угол спокойный для слов; no text, no letters>

- **Текст:** IT'S NOT — чёрный; HUNGRY — белый в красной плашке
- **Запасные:** 2 идеи (образ + слова) — для «Тест и сравнение»

## 3. Описание
<2–3 абзаца крючком, без раскрытия главного ответа> 
<таймкоды глав: 0:00 …>
<строка про ИИ-иллюстрации и проверку фактов>
<2–3 хештега>

## 4. Теги
<через запятую, без кавычек>

## 5. Категория
Education (не для детей)

## Служебное
<тип входа, формула анонса, две линии интереса, источники фактов [CHECK], 2 запасных превью>

## Проверка
<Байт-тест и Тест удержания по пунктам навыка>
```

- Текст превью: 1–3 строки, каждая «СЛОВА — цвет». Цвета: «чёрный» (чёрный с белой обводкой), «белый в красной плашке», «красный» (= плашка). Слова без запятых, точек с запятой и тире внутри. Программа берёт только основной вариант до «Запасные».
- Таймкоды считаются по темпу 160 слов/мин и помечаются как предварительные — программа пересчитает их по готовой озвучке.

## Проверка и упаковка

```bash
python3 природа/_общее/scripts/check_script.py природа/<канал>/сценарии/<NN>_<КЛЮЧ>
```

```bash
python3 природа/_общее/scripts/make_archive.py природа/<канал>/сценарии/<NN>_<КЛЮЧ>
```

Сдача — как у драм: коммит в `main` этого репозитория, архив в `Omajati/avto-scenarii/<папка канала>/` (только `.zip`, выложенные не менять), коммит «Сценарий: <NN>_<КЛЮЧ>» и push, плюс архив владельцу файлом.

## Две мелочи для программы (проверено в коде «Авто ютуб» 214, 18.11.2026)

- В разделе «Служебное» файла загрузки всегда пишем строку `Темп: 160 слов в минуту`. Без неё программа считает таймкоды глав по 150 сл/мин, и к 10-й минуте главы уезжают примерно на 40 секунд раньше.
- Буква в строке `РАСКЛАДКА:` — только латиницей (A–H). Русские Д, Г, Ф программа молча превращает в A.
