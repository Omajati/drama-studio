# Сценарист канала «Морские обитатели»

Канал сети «Животные», только EN. Задача ролика — клик (тема + название + превью) и досмотр (хук, ре-хуки, сквозной вопрос). Общее для всех каналов сети — в `природа/_общее/`; здесь только то, что нужно этому каналу. Где навык расходится с ядром — прав навык.

## Порядок работы над одним сценарием

1. **Журнал.** Прочитай `09_журнал.md`: номер, тема из круга (анонсированную тему не менять), прошлые типы входа, формулы анонса, раскладки.
2. **Тема.** Из круга или из банка (`03_банк_тем.md`, статус «свободна»). Проверь полку: живое существо сегодня, не доисторика. Не два ролика подряд про одно животное (косатки, медузы).
3. **Упаковка до текста.** Название по формуле (`02_правила_канала.md` §4), превью — раскладка C/D/E/F/G, 1–4 слова, не повторяют название. Прогони Байт-тест. Пока нет 8/10 и всех ★ — текст не пишем.
4. **Шапка для себя** (в «Служебное»): тип входа (не как в прошлом ролике), формула анонса (новая), две линии интереса (линия животного/списка + сквозной вопрос, закрыть в финале), особь или случай с именем и годом, 2–3 мифа для развенчания, факты с [CHECK] и источниками.
5. **Озвучка** `озвучка_EN.txt`: 15–20 мин = 2 400–3 200 слов (160 сл/мин), 6–9 глав по 300–450 слов. Сначала черновик с заголовками глав во временном файле, потом чистый текст: без заголовков, без цифр (всё словами), абзацы через пустую строку. Каждая глава — крючок в первой фразе.
6. **Сцены** `сцены_генерация.txt`: шапка по образцу драм, REFERENCE R1… для повторяющегося животного/особи, сцены S001… по одной на 7–8 с (15 мин ≈ 120, 20 мин ≈ 160), в конце каждой — строка стиля канала (`02_правила_канала.md` §8). Схема масштаба с силуэтом человека — минимум одна.
7. **Превью** `превью_EN.txt`: строка `РАСКЛАДКА: <C|D|E|F|G> — <название>`, разделы 1 (картинка без текста, пустое место под слова), 2 (ТЕКСТ, «СЛОВА — цвет»), 3 (ПЛАШКА), 4–6 как в примере. Сетку видов и пирамиду глубины — картинкой в разделе 1 + слова раскладкой C или D.
8. **Загрузка** `загрузка_YouTube_EN.md`: разделы 1–5 + «Служебное» + «Проверка» (обе оценки по пунктам). Раздел «2. Превью» заполнить коротко (запасной путь + 2 запасные идеи). Таймкоды по 160 сл/мин, помечены предварительными.
9. **Проверка:** `python3 природа/_общее/scripts/check_script.py природа/Морские/сценарии/<NN>_<КЛЮЧ> --wpm 160 --min 14 --max 21` — ноль ошибок (фильм-подборка: `--min 110 --max 190`). Плюс чек-лист ниже глазами.
10. **Архив:** `python3 природа/_общее/scripts/make_archive.py природа/Морские/сценарии/<NN>_<КЛЮЧ>` → `<NN>_<КЛЮЧ>.zip` рядом с папкой.
11. **Сдача:** строка в `09_журнал.md` (сданные + входы/превью + «Следующий» с темой анонса) → один коммит в `main` drama-studio («Сценарий Морские 04 КОСАТКИ_ЯХТЫ, EN») и `git push origin main` → архив в `Omajati/avto-scenarii/Животные - Морские EN/` (только `.zip`, выложенные не менять), коммит «Сценарий: <NN>_<КЛЮЧ>» и push → архив владельцу файлом. Коротко по-русски: название, превью, тип входа, объём, оценки тестов.

Длинный текст пиши частями по 2–3 главы, сохраняя в файл.

## Правила канала коротко

- **Полка:** живые морские существа сегодня. Доисторика, мегалодон, мозазавры — Динозаврам. Белый медведь — Зверям.
- **Двигатель:** конкретное большое или странное животное + парадокс. Лучше всего — **особь или случай с именем, местом и годом** (самый большой выброс ниши: две косатки Port и Starboard, ×3 698). Глубина и тьма — фон.
- **Сильные животные:** кашалот, косатка (только с новым углом), ластоногие-хищники, кальмары, гиганты (синий кит, изоподы), акулы списком. Слабые: безымянные «уродливые рыбы».
- **Не делаем:** «уровни океана вообще», «почему не можем исследовать», «Refuses to Kill Us» про косаток, копии чужих историй особей, гравюру со стрелкой на превью.
- **Длина:** 15–20 мин; фильм-подборка 2–3 часа раз в месяц с 4–5 готовых роликов.
- **Визуал:** тёмный цветной подводный реализм, биолюминесценция, человек для масштаба; без крови и узнаваемых людей.
- **Финал:** кольцо к первой сцене, холодная короткая строка, вопрос в комментарии, анонс следующего ролика канала (тема записывается в журнал).

## Байт-тест упаковки (X/10, ★ обязательны)

1. ★ Животное с репутацией или особь с именем — в названии или на превью.
2. ★ Парадокс или ломка ожидания в названии (не трогает нас / боится / второй по / не мирный).
3. Ты-угол или масштаб (you, your, «больше динозавра», человек в кадре).
4. ★ Ответ нельзя угадать по названию + превью; слова превью не повторяют название.
5. Формула и животное не выжаты: сверка с `01_разбор_конкурентов.md` §5 (косатки без особи, слои, доисторика — нет).
6. 40–70 знаков, главное слово в первых 40.
7. Превью: одно существо крупно, тёмный цветной реализм, глаз/пасть/масштаб; не гравюра.
8. 1–4 слова превью, читается на 168×94.
9. Раскладка превью — не третья подряд одинаковая (журнал).
10. Кадр превью есть в первых 5 секундах ролика.

## Тест удержания (X/10, ★ обязательны)

1. ★ Тип входа не как в прошлом ролике; хук ≤ 30 с — сильный вопрос или шок, без разгона.
2. ★ Анонс 2–3 самых странных моментов без названий до 0:45, формула анонса новая.
3. Особь или случай с именем и годом — в первые 2 минуты.
4. ★ Каждая глава открывается крючком (перечислить первые фразы глав); мягких вводных нет.
5. Сквозной вопрос назван в хуке и закрыт только в финале.
6. Масштаб бытовым сравнением в каждой главе + сцена-схема с силуэтом человека.
7. Миф → правда каждые 2–3 главы (назвать мифы).
8. Ре-хук каждые 60–90 с; одна сухая шутка на главу.
9. Кольцевой финал + холодная последняя строка + вопрос в комментарии + анонс следующего ролика.
10. ★ Чистота: цифр в озвучке 0, запрещённых оборотов 0, «not X but Y» не больше одного, `check_script.py` без ошибок.

Обе оценки с разбором по пунктам — в раздел «## Проверка» файла загрузки. Не выполнен пункт — исправить текст, а не оценку.

## Запреты

- Кровь, раны крупным планом, разрывание добычи; постановочные битвы «кто кого».
- Доисторические океаны как тема (только одна глава-отсылка).
- Чужие кадры (BBC, Nat Geo, ROV-видео институтов) и фразы из чужих расшифровок.
- Узнаваемые лица реальных людей в сценах; бренды и логотипы.
- Обороты: «did you know», «in this video», «let's dive in», «nature is amazing», «let that sink in», «it's not X, it's Y» чаще раза за ролик; мягкие начала глав.
- Цифры в озвучке; непроверенные «рекорды» без оговорки «по одной оценке».
- Подача «для детей».

- [ ] Факты с именами и годами проверены по 2 источникам, спорное помечено [CHECK] в «Служебном».
