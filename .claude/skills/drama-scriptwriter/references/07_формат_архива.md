# Формат сдачи: один сценарий = один .zip

Образец, принятый владельцем 18.11.2026: `example/10_РЕЦЕПТЫ/` (ES, 59 мин, 177 сцен). Структуру менять нельзя: эти файлы читает программа «Авто ютуб» (см. `08_авто_ютуб.md`), и любое отступление от имён и разметки ломает автосборку.

## Структура

```
<NN>_<КЛЮЧ>.zip
└── <NN>_<КЛЮЧ>/                 NN — номер темы из плана/банка (две цифры: 01, 10, 31),
    │                            КЛЮЧ — 1–2 русских слова капсом без пробелов (РЕЦЕПТЫ, ДЕНЬ_БЛАГОДАРЕНИЯ)
    ├── озвучка_<LANG>.txt       только текст диктора
    ├── сцены_генерация.txt      промпты картинок, один на все языки
    ├── превью_<LANG>.txt        задание на превью
    └── загрузка_YouTube_<LANG>.md  название, описание, теги, служебное, проверка
```

`<LANG>` — EN, ES, DE или RU, заглавными. Несколько языков в одном архиве: на каждый язык своя тройка `озвучка_<LANG>.txt / превью_<LANG>.txt / загрузка_YouTube_<LANG>.md`, а `сцены_генерация.txt` общий. Больше ничего в папку не класть (никаких заметок, шапок, черновиков): программа ищет файлы по словам «озвуч», «сцен», «превью», «загруз» и может схватить лишнее.

Упаковка: `python3 scripts/make_archive.py <папка>` — без `__MACOSX`, UTF-8 имена. Перед упаковкой `python3 scripts/check_script.py <папка>`.

## 1. озвучка_<LANG>.txt

- Только то, что произносит голос. Ни заголовков глав, ни пометок, ни таймкодов, ни `[пауза]`.
- **Ни одной цифры.** Числа, суммы, годы, время, даты — прописью на языке ролика («sesenta y seis años», «three thousand dollars»). Проверяет скрипт.
- Абзацы разделены пустой строкой. Один абзац — одна мысль/сцена; это помогает программе резать сцены по предложениям и переносить привязку на другие языки (одинаковое число абзацев в переводах).
- Реплики диалога через тире (ES: «—Pues ya está, Lola.»), EN — в кавычках.
- Начало = хук (см. SKILL.md, «Первые три минуты»). Конец = кольцо, последняя строка героини.

## 2. сцены_генерация.txt (английский, plain text)

Порядок блоков строго такой, текст правил копировать из образца дословно, менять только название проекта:

1. `MANDATORY RULE — SCENE NUMBERING (read first, applies to everything below):` + 5 строк правил.
2. `MANDATORY RULE — FILE NAMES:` + 3 строки.
3. `PROJECT CONTEXT:` — проект (длина, жанр, канал, название ролика в кавычках), Story (4–6 предложений сюжета).
4. `Visual style (used for every image): …` — одна строка стиля под сеттинг ролика.
5. `Recurring characters (keep identical across shots):` — каждый персонаж: `ИМЯ — возраст, внешность, одежда; второй образ, если меняется.`
6. `Hard rules:` — 16:9, no text/letters/numbers, no logos/signs/flags/plates, no violence/blood, no real people; экраны и документы размыты; без национальных символов; перечень мотивов-предметов.
7. `CHARACTER AND OBJECT REFERENCES (generate these first and reuse them for consistency):` — `REFERENCE R1. …` … обычно R1–R8: героиня, каждый главный персонаж, дом/место, предмет-мотив. Каждый — отдельный абзац, заканчивается `Style: photorealistic, neutral light, plain background, 16:9, no text.`
8. `SCENES (one image each, in this exact order):`
9. `SCENE S001. …` … `SCENE S177. …` — **каждая сцена отдельным абзацем** (пустая строка между), номер трёхзначный, без пропусков. Внутри сцены: кадр (крупность, действие, место, свет) + персонажи с повтором примет в скобках («The 66-year-old woman (short curly grey hair, round tortoiseshell glasses, dark green cardigan)») + предмет-мотив с описанием в скобках + в конце полный хвост стиля: `Style: <стиль>, 16:9, no text, no letters, no numbers, no logos, no watermark.`
10. Финальная строка `FINAL CHECK BEFORE EXPORT: …` дословно из образца.

Количество сцен: **случайное число от 50 до 100** (решение владельца 18.11.2026; раньше было ~одна на 20 с, 177 в образце). Не упираться каждый раз в 100. Сцены равномерно по тексту, ключевые моменты — своей сценой. Сцены идут в порядке текста; S001 — первая фраза хука. Возраст персонажа в формате «66-year-old» обязателен: по нему программа связывает сцены с референсами.

## 3. превью_<LANG>.txt (русские пояснения, текст на языке ролика)

```
ПРЕВЬЮ <LANG> — <NN> «<короткое имя>»

Ключевая мысль-крючок: … Раскрытие — в первые 3 минуты (…, м:сс).

СТИЛЬ НИШИ <LANG>
<одна-две строки про стиль>

1. ПРОМТ КАРТИНКИ БЕЗ ТЕКСТА (ChatGPT / любой генератор)
<англ. промпт: портрет справа 40%, левые 60% чёрные и пустые, No text, no letters, no logos.>

2. ТЕКСТ СЛЕВА (капс, жирный рубленый шрифт, 5 строк)
СТРОКА ОДИН                              — белый
СТРОКА ДВА                               — жёлтый
СТРОКА ТРИ                               — белый, «ФРАЗА» зелёный

3. ПЛАШКА
Красный прямоугольник внизу слева, белые буквы: <2–4 СЛОВА>

4. ПРОМТ THUMB_<LANG> ДЛЯ FLOW (с точным текстом; подключить R1 и R<N>)
…
Файл: THUMB_<LANG>.png. …

5. ПРОВЕРКА ЧИТАЕМОСТИ
6. СВЯЗКА С НАЗВАНИЕМ
```

Программа разбирает секции по заголовкам «1. …», «2. ТЕКСТ…», «3. ПЛАШКА». Строки текста — формат `ТЕКСТ — цвет`, выделение `«ФРАЗА» цвет` через запятую. Цвета: белый, жёлтый, зелёный, красный, голубой, оранжевый. В секции 3 текст плашки после двоеточия.

## 4. загрузка_YouTube_<LANG>.md

Заголовки `##` дословно (программа ищет их по номеру и слову):

```
# Загрузка YouTube <LANG>: <NN> <короткое имя>
## 1. Название        — одна строка + в скобках число знаков и что видно в первых 40
## 2. Превью          — краткий пересказ превью_<LANG>.txt
## 3. Описание        — синопсис 2–3 абзаца → «уроки» 3–5 пунктов (•) → таймкоды глав (0:00 …) → дисклеймер о вымысле и ИИ → 2–3 хештега
## 4. Теги            — через запятую, без кавычек
## 5. Категория       — People & Blogs; язык видео; метка «Изменённый или синтетический контент»: да
## 6. Субтитры        — .srt по реальной записи
---
## Служебное          — объём (слов, минут, глав), тема плана (№, категория), тип входа (и чем отличается от двух прошлых), хук по секундам, козырь, предмет-мотив и кольцо, голос, сеттинг, механика [CHECK] с нормами закона
## Проверка           — Байт-тест X/10 и Удержание X/10 с разбором по пунктам (см. SKILL.md)
```

Названия глав в таймкодах — для зрителя, интригующие, на языке ролика. Таймкоды предварительные (по 150 слов/мин), это пишется в «Служебном».
