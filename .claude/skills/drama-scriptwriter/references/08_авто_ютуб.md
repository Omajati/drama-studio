# Программа «Авто ютуб» и как сценарии попадают в сборку

Репозиторий: `Omajati/avto-youtube` (публичный, ветка `main`). Программа для Mac: тема → озвучка (ElevenLabs / Lumean / RoyalTechno) → картинки (fal / Fast Gen / Flow) → монтаж 1920×1080 → превью → автовыкладка через Octo Browser. Правила выпуска версий — в `CLAUDE.md` репозитория (работа прямо в `main`, версия в `app/static/index.html`, `bash mac/release.sh "…"`, один коммит, push).

Состояние на 18.11.2026: версия 214.

## Как «Сборка из папок» читает наш архив (app/folder_builder.py, app/upload_package.py)

- Файл сцен: любой .txt/.md, где есть `SCENE S001.` (plain) или `### S001` (markdown-разметка с `Голос:` подсказками). Выбирается тот, где сцен больше; приоритет у имени со словом «сцен». `REFERENCE R1.` — референсы. Сцена = абзац до пустой строки.
- Озвучка: файл .txt со словом «озвуч» и кодом языка в имени (`озвучка_ES.txt`) — «плоский формат», всё в одной папке. Также понимает подпапки EN/ES/DE/RU.
- Загрузка: `*.md` со словом «загруз» и кодом языка. Превью: `*.txt` со словом «превью» и кодом языка.
- Картинки: файлы `S001.png`… в папке проекта (свои) или рисуются программой в подпапку `кадры`.
- Готовое видео: `<папка>/<имя папки>_<LANG>.mp4`, превью рядом, озвучка `озвучка_<LANG>.mp3`.
- Канал для профиля Octo = имя РОДИТЕЛЬСКОЙ папки проекта. Поэтому проекты одного канала лежат в одной папке канала.
- Привязка сцен к тексту: в plain-формате подсказок «Голос:» нет → программа раскладывает сцены равномерно по предложениям. Точнее — режим «ИИ уточняет» в «Привязке сцен». (Идея на будущее: добавить в plain-формат строку `Voice: «первые слова фразы»` и научить парсер её читать — пока НЕ делать в сценариях, программа её не понимает.)
- `__MACOSX` и файлы с точкой в начале игнорируются.

## Раскладки превью — сделано в версии 214 (18.11.2026)

Программа читает `РАСКЛАДКА: A–H` и рисует превью по ней (`compose_layout` в `app/upload_package.py`); без строки — A; позиция строки «…, сверху слева / снизу справа / слева / справа» (для F и G), цвет плашки из раздела 3. Ниже — исходное задание, для истории.

### Исходное задание

Сейчас `app/upload_package.py → compose_left` рисует только одну раскладку: чёрная полоса слева 55–63%, строки слева сверху, красная плашка внизу слева. Нужно (в сессии, где `Omajati/avto-youtube` подключён с правом записи, выпуск по его CLAUDE.md):
- `parse_thumb_spec`: читать строку `РАСКЛАДКА: <A–H>` (по умолчанию A — старые архивы не ломаются); раздел текста искать по слову «ТЕКСТ» (уже так).
- `compose_<код>` для B–H по таблице `references/10_превью_раскладки.md` драм-навыка: B зеркально A (полоса справа, выравнивание вправо, плашка жёлтая справа); C тёмная полоса сверху 35%, 2–3 строки по центру, плашка белая внизу справа; D затемнение снизу 30%, строки внизу, лента-плашка наискосок в правом верхнем углу; E мягкая виньетка, 1–2 огромные строки по центру снизу, маленькая плашка над ними; F строки сверху слева и снизу справа, жёлтая плашка внизу по центру; G граница посередине, строки над половинами, плашка на границе; H «штамп»: красные рамки вокруг строк, плашка-штамп наискосок.
- Цвет плашки — из раздела 3 («красный/жёлтый/белый прямоугольник…»), по умолчанию красный.
- Тест: по одному превью на каждую раскладку на тестовом фоне 1920×1080 + проверка читаемости уменьшением до 168×94.
- Пока не сделано: превью с раскладкой не A владелец делает по разделу 4 (Flow) и кладёт `превью_<LANG>.png` в папку проекта — `finished_thumb` берёт его как есть.

## Каналы (ниши) — с версии 213

- Канал = папка, в которой лежит проект. Одно имя везде: `avto-scenarii/<канал>/`, `входящие/<канал>/`, `рабочая папка/<канал>/<проект>/`.
- Действующие и запланированные папки: `Семейные драмы ES`, `Животные - Звери EN`, `Животные - Динозавры EN`, `Животные - Морские EN`, `Животные - Насекомые EN`, `Истории RU`.
- У канала в «Сборке из папок» → «Каналы (ниши)» свои настройки: языки, голоса, музыка, стиль/темп монтажа, эффекты, субтитры, превью, выкладка, профиль Octo. Без своих — общие, язык из конца имени папки (EN/RU/DE/ES).
- Настройки берутся при постановке в очередь. Сценарию ничего добавлять не нужно — важна только папка, куда кладётся архив.
