# Drama Studio

Сценарии канала семейных драм («тихая месть», рассказчица-вдова 63–72) для программы «Авто ютуб».

Как работать: начать сессию Claude Code с этим репозиторием и написать, например, «пиши №31» или «давай следующий». Правила и журнал — в `.claude/skills/drama-scriptwriter/`, готовые архивы — в `сценарии/`.
